# Plugin Universe Plan

An online database of Digital Audio Workstation plugins.

RDF-backed content management system with integrated Semantic Search

* Plugins each get a Plugin Profile and Wiki page, with ranking and comment thread
* Registered users get a Wiki page & FOAF Profile

Three user tiers (plus admin) :

* Pro - allows promotion of plugins, unfiltered query page, (on topic) advertising, ability to blog
* Registered user - ability to add plugins, comment on Wiki
* Public

## Business model

* Open Data
* Free public access with restrictions
* Paid pro accounts

## Promotion

The public-facing search has its results filtered to the advantage of promoted plugins
